# Yashwanth Mirapala Portfolio

A responsive dark-themed developer portfolio built with HTML, CSS and JavaScript.

## Files

- index.html
- style.css
- script.js
- assets/

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing

1. Put your real profile photo at `assets/profile.jpg`.
2. Put your latest resume at `assets/Yashwanth-Resume.pdf`.
3. Replace each project GitHub link with the correct repository.
4. Replace each "Live Demo" placeholder with the real deployed URL.
5. Update the contact details if needed.
6. Push the folder to GitHub and deploy with GitHub Pages, Netlify or Vercel.

## Important

The contact form is currently a front-end demo. It does not send email until connected to a backend/form service.
